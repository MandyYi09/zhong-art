# Canonical project

This repository is the source of truth for Zhong Art. The desktop zhong-art folder is a symbolic link to this checkout; it is not a second copy.

Publish changes by committing and pushing main, checking the Publish website workflow for that exact commit, and opening https://mandyyi09.github.io/zhong-art/.

The portfolio opens this canonical public site. Do not patch a compiled copy in my-website to change Zhong Art. Preserve source images and local print/design artifacts. Build outputs, local launchers, caches and private environment files stay out of commits.
