# 水陆画卡片人物与版本年代核对

核对日期：2026-10-24。姓名以图像原题签为先；现代卡片英文设计标题不等于神祇名称。

## 年代依据

原有20个图像文件已逐张与天理图书馆藏《九天应元雷声普化天尊说玉枢宝经》彩绘本影印图作视觉对应。馆方[展览著录](https://www.tcl.gr.jp/exh/exh-2298/)第5付记“嘉靖6(1527)写”；[同版影印图](https://www.sohu.com/a/537724050_483936)可核对题签、姿态、服饰与配色。因此网站标注“明嘉靖六年（1527）彩绘本”。这是版本年代，不是神仙出生年，也不证明用户所拍印刷载体本身作于1527年。不可误用书格另一万历四十七年（1619）版本年代。

## 需要保留的区别

- SL-05 / 5688 的蓝底题签字迹不清，姓名尚待更高清原书图像复核，不将猜测写成定论。
- SL-14 / 5697 2 与 SL-16 / 5699 是同一神雷石元帅原图的不同裁切，保留源文件和既有设计；网站只展示5697 2，旧5699链接指向该图。新增9549和438后，当前图集共21幅（19幅常规款、2幅隐藏款）。
- SL-17 / 5702 的一幅图内有王、高二元帅，须保留两位名称。
- SL-13 / 5696 2 按原题签释“风轮周元帅”。本地《水陆画图像研究》一校稿图10-23的说明存在与图不符之处，不沿用其“铁元帅”图注。
- SL-21 / 9549：用户补充姓名为杨任，称号线索为“甲子太岁金辩大将军”；书名、页码暂缺。用户给出的公元前1007年、商纣王时期仅列为待核人物传说线索，不是原画年代。新卡通图是2026年当代改编。等书名与原页补齐后再核查称号与原画年代。

## 本次完整性检查

22条图像记录（含1条重复照片兼容记录）均有中英文名称、年代说明与来源说明。19幅在展示的《玉枢宝经》图像沿用已记录的题签对应，馆方著录第5付的1527年版本年代本次再次核对。图集和详情直接展示出处；详情补充逐图影印位置或用户供图文件名。

仍待考的三项：5688题签全称；9549原书书名、页码及原画年代；438原作出处及年代。438名称据图中题字记为斗姆元君，不能从同名作品或2026年卡通改编时间推定原画年代。本次未找到足以确认两张用户供图原作年代的资料，保留待考，不补猜测年份。
