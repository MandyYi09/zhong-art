# Modern Shuilu legacy redirect

This repository keeps previously shared website links working.

- Website: https://mandyyi09.github.io/modern-shuilu/
- Canonical source: https://github.com/MandyYi09/modern-shuilu

Both the homepage and the 404 fallback redirect to Modern Shuilu, preserving the page path, query string, and fragment. JavaScript-disabled browsers fall back to the homepage.

Do not put application source or artwork in this redirect repository.
